Automated Network Penetration Testing Framework Using Reinforcement Learning

June 2025 – October 2025 BRAC University Dr. Muhammad Iqbal Hossain & Dr. Swakkhar Shatabda

Undergraduate thesis focused on reinforcement learning–based automated network penetration testing and realistic, configurable simulation environments for security research.

  • Led the development of NASimEmu-enhanced, extending the NASimEmu simulator for more realistic and configurable penetration-testing environments
  • Implemented dynamic v2 scenario generation with per-episode stochastic sampling, including variable subnet sizes and randomized host, service, and process configurations
  • Added host-state variability and controlled stochastic noise to reduce overfitting to static networks and improve policy robustness
  • Refined the environment lifecycle and scenario-loading pipeline so each episode is regenerated consistently while preserving stable step-level simulation behavior
  • Built reproducible experiment workflows for training, tracing, debugging, and evaluating agents across multiple scenario types
  • Developed comparison and analysis tooling to assess agent performance across static versus dynamic network conditions
  • Authored technical documentation, including scenario guides, command references, and debug workflows, to support repeatable research and collaboration
